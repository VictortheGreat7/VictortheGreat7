# Hey, I'm Victor 👋

### A bit about me

I'm a cloud & DevOps engineer based in Nigeria, fascinated by the infrastructure
that keeps modern software running — the pipelines, the orchestration, the
automation that makes it all feel effortless (until it doesn't 😄).

I'm currently building out a full GitOps setup on DigitalOcean, wiring together
Kubernetes, ArgoCD, and Terraform to see how far I can take a production-grade
workflow on a personal project.

### What I'm working on

- 🔭 **[DOKS GitOps Setup](https://github.com/VictortheGreat7/digital-ocean-full-stack)** —
  a full-stack GitOps deployment on DigitalOcean Kubernetes, using Terraform for
  infra provisioning and ArgoCD for continuous delivery.
- 🏗️ **[Self-hosted Full Stack](https://github.com/VictortheGreat7/self-hosted-full-stack)** —
  experimenting with private cluster access, provisioning and modifying cloud infrastructure (`terraform apply`) from a self-hosted Github Actions runner.

### What I'm learning

I'm deep in the DevOps toolchain right now: **ArgoCD, Terraform, Kubernetes,
Docker, Bash, and Python**. The cloud providers I'm hands-on with are
**DigitalOcean** and **Azure**.
